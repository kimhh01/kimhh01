# 🌟 주요 프로젝트

## 🏫 ClassMate

### 스마트 캠퍼스 길찾기 & 학사 도우미 Android 앱

**Beacon과 QR코드를 활용하여 캠퍼스 내부·외부의 위치를 탐색하고**
**학생들의 학교생활을 지원하는 스마트 캠퍼스 애플리케이션**

### 주요 기능

* 🗺️ Naver Maps API 기반 캠퍼스 지도 및 외부 길찾기
* 🧭 Beacon 기반 실내 위치 탐색
* 📷 QR 코드 기반 실내 위치 인식
* 🏢 강의실 검색 및 실내 경로 안내
* 📅 시간표 추가 / 수정 / 삭제
* 🏫 학교 홈페이지 및 SNS WebView 연동
* 💬 FAQ 및 SMTP 기반 문의 기능
* 📦 JSON 및 SharedPreferences + Gson 기반 데이터 관리

### 기술 목록

`Kotlin` `Android` `Java` `Naver Maps SDK` `BLE` `Beacon` `ZXing` `WebView` `SMTP`

## 🤝 ChemiQ

### 파트너와 함께 미션을 수행하는 미션 기반 커뮤니티 웹 서비스

**React 기반 SPA로 구현된 파트너 매칭 및 미션 커뮤니티 플랫폼**

사용자는 파트너를 신청하거나 수락하고,
함께 다양한 미션을 수행하며 활동을 기록하고 평가할 수 있습니다.

### 주요 기능

* 👤 회원가입 / 로그인 / 로그아웃
* 🔐 JWT 기반 사용자 인증
* 🤝 파트너 신청 및 관리
* 🎯 오늘의 미션 조회 및 수행
* 📷 미션 인증 및 제출
* 📜 미션 수행 이력 조회
* ⭐ 파트너 평가
* 👤 프로필 및 회원정보 관리
* 🔄 REST API 기반 백엔드 연동

### 기술 목록

`React` `JavaScript` `React Router` `Axios` `REST API` `JWT` `CSS3`

## 🤖 Skincare AI Assistant

### GPT-4 + RAG 기반 스킨케어 제품 추천 및 상담 AI 서비스

**실제 스킨케어 리뷰 및 분석 데이터를 검색하고**
**GPT-4를 활용하여 사용자에게 제품 추천과 상담을 제공하는 AI 웹 서비스**

### 주요 기능

* 🤖 자연어 기반 스킨케어 상담
* 📚 RAG 기반 리뷰 및 분석 데이터 검색
* 🔍 FAISS 벡터 유사도 검색
* 💬 이전 대화 맥락을 활용한 연속 대화
* 🧴 스킨케어 제품 추천
* 📊 리뷰 및 분석 데이터 활용
* 🎨 Streamlit 기반 웹 인터페이스
* ⚡ FastAPI 기반 REST API 제공

### 기술 목록

`Python` `FastAPI` `Streamlit` `OpenAI GPT-4` `LangChain` `FAISS` `Pandas`
